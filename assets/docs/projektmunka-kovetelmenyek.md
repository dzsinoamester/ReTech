# Projektmunka követelményei

## 1. Alapadatok

IKT projektmunka, minden csapat saját témakörben valósítja meg a követelményeket.

## 2. Használt alkalmazások

- Trello
- Figma
- GitHub
- HTML
- Bootstrap
- CSS
- JS
- NodeJS

## 3. Projektfeladatok

- Drótváz készítés
- Designe tervek készítése
- Feladatkiosztás
- Git vezetése beszédes commitokkal
- HTML oldal
- Responsive minden készülékméreten
- Javascript frontenden
- NodeJS backend (Csak GET hívás)

## 4. Elvárások

### Kötelező elvárások

- Drótváz
- Designe tervek
- Feladatmegosztás
- Git vezetése
- Responsive weboldal minden eszközön
- NodeJS szolgálja az adatokat
- Szűrt/rendezett adatokat a backend adja vissza
- Cart (vagy hasonló) adatösszesítő a kliens oldalon
- PPT-vel vagy Prezivel megtámogatott bemutató
- A bemutató során a csapat minden tagja ki kell vegye a részét és ismernie kell a teljes folyamatot

### Minőségi elvárások

- A projekt jól használható és könnyen áttekinthető legyen
- Hibás vagy hiányos adatok esetén adjon értelmes visszajelzést
- A forráskód rendezett és érthető

## 5. Prezentáció

- a projekt célját
- a megvalósított funkciókat
- a használt alkalmazásokat és technológiákat
- a felmerült problémákat és azok megoldását
- a csoporttagok munkamegosztását
